# Worksheets

Drop worksheet and tool files into the folder for their segment, then add a
`file:` line to the matching entry in `../assets/data.js`. Full instructions are
in `../README.md`.

Naming: lowercase, hyphens instead of spaces — `cash-flow-forecast.xlsx`, not
`Cash Flow Forecast.xlsx`. Spaces have to be percent-escaped in URLs and are an
easy way to end up with a broken download link.

The `.gitkeep` files exist only so git tracks these empty folders; delete them
once a folder has real files in it, or leave them alone.
